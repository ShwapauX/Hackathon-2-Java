# 📖 Proyecto Agenda Telefónica en Java

Un sistema de gestión de contactos desarrollado en **Java** diseñado para administrar una libreta de direcciones mediante consola aplicando conceptos de Programación Orientada a Objetos (POO).

## 🛠️ Funcionalidades del Sistema

-**`Añadir contacto`**: Permite registrar un nuevo nombre y número telefónico en la agenda.

-**`Existe contacto`**: Comprueba si un registro específico ya se encuentra guardado.

-**`Listar contactos`**: Muestra la lista completa de todos los contactos almacenados.

-**`Buscar contacto`**: Localiza la información de un contacto a partir de su nombre.

-**`Eliminar contacto`**: Remueve un contacto seleccionado de la agenda.

-**`Modificar teléfono`**: Actualiza el número de contacto de un registro existente.

-**`Agenda llena`**: Valida si la agenda ha alcanzado su capacidad máxima de almacenamiento.

-**`Espacios libres`**: Informa cuántos registros adicionales se pueden agregar antes de llenar la agenda.
